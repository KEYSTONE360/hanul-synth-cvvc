# Hanul Synth CVVC

`run.bat`을 실행하면 프로그램이 열립니다.

## 음원 구성

- CV 음원 399개
- 모음에서 다음 자음으로 이어지는 VC 음원 399개
- 모음에서 받침으로 이어지는 전이 음원 147개
- 총 945개 WAV
- 인간 음성 녹음 미사용
- 기본음 440Hz(A4)
- 1~36배음 사인파 가산합성

합성식:

`x(t) = Σ Aₖ(t) × sin(2πfₖt + φₖ) + n(t)`

`Aₖ(t)`는 모음의 포먼트와 전이 구간에 따라 변합니다. 자음 잡음은 자음별로
정해진 중심 주파수와 대역폭 안에서 생성됩니다.

## 음색 배합

- 선명하고 안정적인 전자음: 42%
- 밝고 빠른 여성형 어택: 38%
- 홀수 배음과 얇은 비강 공명: 20%

특정 캐릭터의 실제 음성을 복제하지 않고 레이·테토 계열에서 연상되는
밝고 얇은 전자적 여성 음색을 가산합성으로 설계했습니다. 마찰성 무작위 잡음은
줄이고 배음의 규칙적인 질감으로 기계적인 느낌을 냅니다.

## 합성 성분 출력

- `voicebank/sine_components.csv`: 각 WAV에 사용된 모든 사인파의 주파수,
  시작·끝 진폭, 위상
- `voicebank/noise_components.csv`: 각 자음 잡음의 중심 주파수, 대역폭,
  세기와 생성 seed
- `voicebank/synthesis_design.json`: 포먼트, 배합 비율, 합성식
- `voicebank/manifest.json`: 프로그램에서 사용하는 945개 음원 목록

프로그램의 `도움말 → 사인파 성분표 열기`에서도 확인할 수 있습니다.

## 키보드와 가사

- `Z S X D C V G B H N J M`: 도5~시5
- `Q 2 W 3 E R 5 T 6 Y 7 U I`: 도6~도7
- `← / →`: 입력 위치 이동
- `Space`: 재생
- `Ctrl/Shift + 클릭`: 음표 여러 개 추가 선택·해제
- `Ctrl+A`: 전체 음표 선택
- `Delete`: 선택 음표 일괄 삭제
- 음표 드래그: 위·아래로 음높이 변경, 좌·우로 1/4박 단위 위치 변경
- 여러 음표를 선택한 뒤 드래그하면 선택 묶음을 함께 이동

## 빈 박자 일괄 줄이기

`타이밍 정리`에서 허용할 최대 빈 박자를 `0, 0.25, 0.5, 1, 2박` 중
선택한 뒤 `빈 박자 일괄 줄이기`를 누릅니다. 선택한 값보다 긴 빈 구간만
곡 전체에서 압축하며 음표 길이, 가사, 음높이와 기존 겹침은 유지합니다.
예를 들어 1박 쉼에 최대값 0.25박을 적용하면 그 쉼은 0.25박으로 줄어듭니다.
- 음표 더블클릭 또는 `F2`: 개별 가사 입력
- 음표와 건반 이름은 `도·레·미·파·솔·라·시`로 표시
- 상단 가사 입력창에서 Enter: 한글 한 음절씩 음표 순서대로 자동 배치
- 자동 배치에서 띄어쓰기 한 구간은 음표가 없는 1박 쉼으로 변환
- 연속된 공백 여러 개도 한 번의 1박 쉼으로 처리
- 가사보다 음표가 부족하면 마지막 음높이로 부족한 음표를 자동 생성
- 음표가 하나도 없으면 도5부터 가사 수만큼 자동 생성
- 가사를 입력하고 음표를 수동으로 추가하면 다음 한글 음절이 차례대로 자동 입력
- 가사 내용을 수정하면 수동 입력 순서가 첫 음절부터 다시 시작

`음색`에서 `기계적` 또는 `부드러운 여성`을 선택할 수 있습니다.
`외부 반주 트랙`에서 별도 WAV 파일을 불러오고 반주 볼륨을 조절할 수 있으며,
파일 경로와 볼륨은 프로젝트에 함께 저장됩니다.
`나비야_예제.hsp`에는 `나비야 나비야 이리 날아오너라`가 배치되어 있으며,
두 음색의 WAV 미리듣기와 소프트 패드 반주가 포함된
`나비야_예시음원.wav`가 함께 들어 있습니다.

`배음 사이 잡음`의 기본값은 0%입니다. `기계음` 슬라이더는 31Hz 진폭 변조,
1.5·2.5배 서보톤, 단계적 양자화를 동시에 조절하며 기본값은 3%입니다.
모음에는 약한 5Hz대 피치·세기 변화가 적용되며 잔향이나 에코는 없습니다.
